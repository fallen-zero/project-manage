# M6 Windows 图片 OCR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `png/jpg/jpeg/webp/bmp` 里的中文/英文文字经 Windows 原生 OCR 进入全文索引，可被 `search_all` 正文段命中与预览。

**Architecture:** 新增纯能力模块 `src-tauri/src/ocr.rs`（`ocr_available` 探测 / `image_text` 识别 / `clean_cjk_spaces` 清洗）；OCR 挂在既有 `extract_text` 分派的**抽取阶段**（`run_pass` 内、写锁外，与 PDF 同侧），写库仍走 `write_doc`→`index_text`（jieba）不改分词链。OCR 语言包不可用时，图片在 `index_scan` 的门那一层退回「不建行」，与今天 png 作为未支持类型完全同一条路径。`IndexOverview` 加**一个** `ocr_available` 字段供 `/index` 降级提示。

**Tech Stack:** Rust 2021；`windows = "0.62.2"`（本批新增，`Media::Ocr`/`Graphics::Imaging`/`Storage` 等 feature）；rusqlite 0.40.2 bundled / jieba-rs / 既有 walkdir 扫描。前端 React + TS（`index_overview` 一个布尔 + 一处文案）。

**Spec:** `docs/superpowers/specs/2026-10-12-m6-ocr-design.md`（决策 D1–D7、判据 §四、降级 §五/D3–D4、真机断言 §八、风险 §十；分歧以 spec 为准）

```rust
//! Windows 原生图片 OCR（M6）。能力层三件事：探测可用性、识别、清洗 CJK 词间空格。
//! 只读图片、绝不写回；识别文本交回调用方（extract_text）走既有分词入库。
use std::sync::OnceLock;

/// 本机有没有可用的 OCR 识别器（任一语言）。进程内探一次记忆化——`AvailableRecognizerLanguages`
/// 取值有成本，且降级判据必须全局一致（别在同一轮里忽有忽无）。探测抛错按「不可用」保守处理。
pub fn ocr_available() -> bool {
    static OK: OnceLock<bool> = OnceLock::new();
    *OK.get_or_init(|| match windows_probe() { Ok(v) => v, Err(_) => false })
}

fn windows_probe() -> windows::core::Result<bool> {
    use windows::Media::Ocr::OcrEngine;
    let langs = OcrEngine::AvailableRecognizerLanguages()?;
    // Size 是 u32；>0 即本机至少能建一个识别器（不断言必须中文：有英文包时英文图也能 OCR，D3）。
    Ok(langs.Size()? > 0)
}

/// Windows OCR 会在 CJK 字符间插空格（「合 同 验 收」）。仅当**空格两侧都是 CJK** 才删该空格，
/// 保留英文词之间的空格（D7，借 dowse 设计）。
pub fn clean_cjk_spaces(s: &str) -> String {
    let is_cjk = |c: char| matches!(c as u32,
        0x3000..=0x303F | 0x3400..=0x4DBF | 0x4E00..=0x9FFF | 0xF900..=0xFAFF | 0xFF00..=0xFFEF);
    let chars: Vec<char> = s.chars().collect();
    let mut out = String::with_capacity(s.len());
    for i in 0..chars.len() {
        let c = chars[i];
        if c == ' ' && i > 0 && i + 1 < chars.len()
            && is_cjk(chars[i - 1]) && is_cjk(chars[i + 1]) {
            continue; // 两侧皆 CJK 的空格删掉
        }
        out.push(c);
    }
    out
}
```
