# 项目资料管理系统 操作手册

**适用版本**：0.1.0（2026-10-26）
**适用系统**：Windows 10 / 11
**数据位置**：本机 SQLite 数据库，界面底部会显示实际路径（通常在 `%APPDATA%\dev.zero.pfm\ledger.db`）

> 本手册按当前版本的实际界面编写。软件只登记路径和资料，**不会移动、修改、重命名或复制你的原始项目文件**。

## 1. 安装与启动

1. 双击安装包 `项目资料管理系统_0.1.0_x64-setup.exe`，按向导完成安装。
2. 安装包未做代码签名，Windows 可能弹出 SmartScreen 提示；确认来源可信后选择「更多信息 → 仍要运行」。
3. 从开始菜单或桌面快捷方式启动「项目资料管理系统」。
4. 首次启动会在本机创建数据库；不需要联网，也不会上传任何资料。
5. 需要开机自动启动时，打开右上角齿轮「设置」，勾选「开机自启」。

**卸载前请先导出备份包**（见第 12 节）。卸载程序不会替你保留数据。

## 2. 界面总览

顶部导航：

| 入口 | 用途 |
|---|---|
| 搜索 | 跨项目搜索档案、台账、待办、日报、到期事项和文档正文 |
| 项目 | 项目档案列表、新建/编辑/删除、模板 |
| 索引 | 为项目目录建立/更新全文索引，查看进度与失败原因 |
| 备份 | 导出、检查、导入整库备份包 |
| 待办 | 跨项目待办，三种视图 |

| 日志 | 项目档案字段级修改日志 |

右上角：

- **工作区切换器**：切换当前项目视野；「管理」里可新建/重命名/删除工作区。
- **齿轮（设置）**：开机自启。
- **主密码控件**：设置、解锁、锁定、更换主密码。

底部状态栏：数据库路径、WAL 模式、库结构版本、FTS5 是否可用。

## 3. 首次使用建议

建议按下面顺序开始：

1. **设置主密码**（右上角主密码控件 → 设置主密码），把恢复码抄到安全位置。
2. **新建项目**，填写名称、客户、联系人等基础信息。
3. **登记主根目录**，需要时再登记子目录/文件快捷入口。
4. **填写信息台账**：环境地址、账号凭据、服务器、外部链接、备注。
5. **添加待办和日报**，把正在做的事挂到项目上。
6. **建立索引**，让文档正文可以被搜索。
7. **导出一次备份包**，确认备份路径和恢复流程可用。

主密码不是开机锁：它只保护台账里的账号、密码等敏感字段。项目名、客户、备注、日报等内容在未解锁时仍可查看（见第 13 节）。

## 4. 项目档案

### 4.1 新建项目

在「项目」页点新建，填写：

- 项目名称（必填）
- 项目编号、项目经理
- 客户名称、对接联系人、联系方式
- 合同编号、合同周期、交付截止
- 项目状态：立项 / 需求 / 开发 / 测试 / 预发 / 上线 / 运维 / 归档
- 项目标签：自由填写，例如政务、自研、外包、已验收、暂停、维保中
- 所属总包：选择已有项目作为父项目，留空即顶层项目
- 工作区：新项目落在当前活动工作区

也可以先建**项目模板**，新建项目时用「从模板填充」带出常用字段。

### 4.2 编辑与删除

- 项目卡片上点编辑，修改后立即写回本机库，不影响磁盘文件。
- 删除项目前请确认；删除后项目会从列表和检索中消失。
- 子项目换工作区不能单独操作，会随父项目一起移动。

### 4.3 父子项目

- 选中父项目后，可在详情页看到「子项目」列表。
- 父项目换工作区时，整棵子树一起跟随；子项目的工作区选择框会锁定。
- 顶层项目可以单独换区。

## 5. 项目详情

选中项目后，右侧从上到下依次是：基础信息、本地目录映射、信息台账、项目里程碑、项目版本台账、到期事项。

### 5.1 本地目录映射

- **主根目录**：一个项目只能登记一个，用于「打开本地项目文件夹」和「复制本地路径」。
- **快捷入口**：可登记多个子目录或文件，例如需求文档、方案、会议纪要。
- 「选择目录」「选择文件」只登记绝对路径；软件不会复制或改动这些文件。
- 入口行支持打开、在资源管理器中定位、复制路径。

### 5.2 信息台账

#### 多环境地址

- 环境：开发 / 测试 / 预发 / 生产。
- 每条记录可填名称、访问地址、端口、备注。
- 地址可一键复制。
- 前后端可以登记成两条记录，用名称区分。

#### 账号凭据

- 字段：标题（用途）、所属环境、账号、密码、登录地址、备注。
- 账号和密码加密存储；列表只显示「有没有值」，不显示明文。
- 点眼睛图标查看/隐藏，点复制图标复制；需要先解锁主密码。
- 锁定后已显示的明文立即不可读。

#### 服务器

- 字段：名称、IP/域名、堡垒机、远程账号、密码/私钥口令、备注。
- 远程账号和密码同样是加密字段，查看/复制需要解锁。

#### 外部链接

- 归类：Jira / 禅道 / Wiki / 文档 / 代码库 / 其他。
- 字段：标题、地址、备注；地址可复制。

#### 备注台账

- 字段：标题、标签、正文；正文支持换行，适合记接口信息、回调地址、坑点、遗留问题、需求变更。
- 展开备注可查看正文和截图缩略图。
- **粘贴截图**：先保存备注，再点编辑；在编辑对话框里直接粘贴截图（Ctrl+V）。
  - 支持 PNG / JPEG / WebP。
  - 单张不超过 5 MB，每条备注最多 10 张。
  - 截图立即入库，与「保存/取消」按钮无关；取消编辑不会撤销已粘贴的图。
  - 缩略图右上角的删除按钮可单张删除。
  - 截图会随整库备份一起进备份包。

#### 台账导出

项目详情里的「导出台账」支持 Excel 或 Markdown，导出当前项目的五类台账（环境、凭据、服务器、链接、备注）。

- 默认不导出账号密码明文。
- 勾选「包含账号与密码明文」会先弹二次确认；导出文件不受主密码保护，拿到文件的人可以直接看到明文。

### 5.3 项目里程碑

- 阶段固定五段：立项 / 评审 / 联调 / 上线 / 验收。
- 可记录计划日期和备注；勾选表示已完成，勾掉表示未完成。
- 里程碑没有「编辑」：写错了删除后重建。
- 待办页顶部会汇总临期/逾期的里程碑、待办和到期事项。

### 5.4 项目版本台账

- 字段：版本号（必填）、上线时间（必填）、本次上线内容（可空）。
- 同一项目内版本号不能重复；删除后的版本号可以重新使用。
- 上线内容按全文换行展示，不截断。
- 支持新增、编辑、删除。

### 5.5 到期事项

- 种类：维保 / 域名 / 证书 / 其他。
- 字段：名称、到期日期、备注。
- 续期就改到期日期；不再需要就删除。
- 到期事项会进入待办页的预警汇总。

## 6. 待办清单

待办是跨项目的独立栏目。

- 新增：选项目、填内容、可选截止日期。
- 编辑：点待办上的「编辑」，修改内容或截止日期。
- 完成/取消完成：点勾选框。
- 删除：点垃圾桶。
- 筛选：顶部按项目筛选，可选「全部项目」。
- 三种视图：
  - 全部
  - 按项目分组
  - 按截止排序
- 无截止日期的待办会单独标注；今天到期、已逾期的有不同提示。

## 7. 日报与工时

### 7.1 填写日报

字段：日报日期、所属项目、工作内容、工时（小时）。

- 每条日报必须挂一个项目。
- 支持新增、编辑、删除。
- 「复制上一天」会把**所选日期之前最近一个有日报的那天**的条目复制到当前日期；不是机械复制前一天的日历日期。
- 复制前会确认，避免重复复制。

### 7.2 查询与汇总

- 筛选：起始日期、结束日期、所属项目、工作内容关键词。
- 汇总口径：
  - 按日 / 按周 / 按月累计工时
  - 按项目汇总工时
- 日期不是 `YYYY-MM-DD` 的脏数据会在界面上提示，不进入汇总。

### 7.3 Excel 导出与导入

- **导出当前范围**：把当前筛选后的日报导出为 `.xlsx`，所见即所得。
- **导入**：
  1. 用「日报模板.xlsx」填写，列包含日期、项目、工作内容、工时。
  2. 选择文件后先做预检，界面会列出可导入行和不合格行。
  3. 确认后一次性写入；不合格行不会被静默丢弃。
- 项目名必须能匹配到现有项目，否则该行会被拒绝。

## 8. 全局搜索

- 输入关键词，匹配：项目名/编号/负责人/客户/联系人/联系方式/合同信息、环境地址、凭据标题与地址、服务器、外部链接、备注、待办、日报内容、到期事项。
- 文档正文搜索依赖索引：先在「索引」页建立索引。
- 搜索结果按来源分组，点结果可跳到对应项目。
- 搜索只显示当前工作区的数据。
- 账号密码明文不参与搜索。

---

## 9. 索引

- 在「索引」页选择项目后点「建立索引」，可查看进度、取消、重新读取文件清单。
- 支持常见的文本/代码文件、Word/Excel/PPT/PDF、常见图片等。
- 图片文字识别（OCR）依赖 Windows 语言包；不可用时图片不会建索引，页面会提示。
- 旧版 `.doc` / `.ppt` 需要本机安装 LibreOffice；页面提供安装入口，装好后重新扫描。
- 跳过/失败会显示原因：超出单文件上限、正文为空、类型暂不支持、文件已不存在等。
- 索引**不进备份包**；导入备份或换机器后需要重新建立索引。

## 10. 操作日志

- 记录项目档案的新建、编辑、删除。
- 编辑日志按字段记录旧值/新值（例如客户名称、联系人、工作区）。
- 可按项目、动作筛选，分页加载。
- 日志只追加，不提供编辑/删除界面。
- 日志只显示当前工作区的项目。

## 11. 工作区

工作区用于按客户/项目类型分视野，是**逻辑隔离，不是权限控制**。

- 顶栏切换器切换当前工作区；切换后项目、台账、待办、日报、检索、日志都按当前工作区显示。
- 「管理」里可新建、重命名、删除工作区。
- 默认工作区不能删除；非空工作区不能删除（先移走或删除其中的项目）。
- 重命名只改显示名，不影响项目归属。
- 项目换区时，整棵子树一起移动；子项目不能单独换区。

## 12. 备份与恢复

### 12.1 导出备份包

- 在「备份」页点「导出备份包」，选择数据目录以外的保存位置。
- 备份包是 zip，包含整库数据：项目、台账、待办、日报、里程碑、版本、到期事项、操作日志、备注截图、设置。
- **索引不进包**，包体积更小，恢复后重建即可。
- 导出落点不允许指向应用数据目录，避免覆盖活库或应急包。

### 12.2 检查备份包

- 点「检查备份包」选择文件，可查看导出时间、库版本、各表条数和明文告警。
- 检查是只读的，不会动当前库。

### 12.3 导入备份包

- 点「用备份包导入」，选择包并确认「导入将覆盖当前整库」。
- 导入前会在数据目录自动留一份 `pre-restore-*.zip` 应急包；导入出问题可用它导回。
- 导入后索引为空，需要重新建立索引。
- 比当前应用更新的库版本会被拒绝；旧版本包会自动升级。
- 导入会覆盖当前工作区、项目、台账、待办、日报等全部数据，导入前请先导出当前备份。

### 12.4 换电脑

1. 在新电脑安装同版本或更新版本的应用。
2. 导入旧电脑的备份包。
3. 用主密码解锁；如忘记主密码，用恢复码重置。
4. 重新建立索引。

## 13. 主密码与敏感字段

- 首次使用可在右上角设置主密码；设置时会展示一次性恢复码，请抄到安全位置。
- 主密码用于加密台账里的账号、密码、服务器远程账号等敏感字段。
- 解锁后才能查看/复制这些字段；锁定后立即不可读。
- 更换主密码需要旧主密码；恢复码可在忘记主密码时重置。
- 恢复码只展示一次；主密码和恢复码都丢失时，敏感字段无法解密，备份包也不能绕过。
- **主密码不是开机锁**：未解锁时项目名、客户、备注、日报等明文数据仍可查看。整机安全请依赖 Windows 账户密码和磁盘加密。
- 备份包本身不加密，里面包含明文列；请把包放在可信位置，不要发到公共群/共享盘。

## 14. 设置：开机自启

- 右上角齿轮 → 勾选「开机自启」。
- 开启后会在当前 Windows 用户的登录项里登记本应用的绝对路径；关闭即删除。
- 移动安装目录、重装或改名后，旧路径会失效，请重新关闭再开启一次。
- 如果开启失败，检查安全软件是否拦截注册表写入；错误提示会给出注册表位置。
- 该设置是**本机偏好**，不随备份包迁移。

## 15. 常见问题

**Q：为什么账号/密码显示成点点点？**
A：未解锁主密码。点右上角主密码控件解锁后才能查看/复制；锁定后立即隐藏。

**Q：忘记主密码怎么办？**
A：用设置时展示的恢复码重置。恢复码也只展示一次；两者都丢失时敏感字段无法恢复。

**Q：打开软件为什么没要求输入主密码？**
A：主密码只保护台账里的敏感字段，不是整应用锁。项目名、备注、日报等明文数据在未解锁时仍可查看。

**Q：备份包里有什么？安全吗？**
A：整库数据（含截图），不含索引。包不加密，含明文列；请妥善保管，不要外发。

**Q：换电脑后账号密码还能看吗？**
A：能，但需要主密码或恢复码；备份包本身不能解密。

**Q：开机自启没生效？**
A：移动/重装后重新开关一次；确认安全软件没有拦截注册表；错误提示会给出注册表位置。

**Q：粘贴截图没反应？**
A：先保存备注，再点编辑，在编辑对话框里粘贴；只支持 PNG/JPEG/WebP，单张 ≤5 MB，每条 ≤10 张。

**Q：文档正文搜不到？**
A：先在「索引」页建立/更新索引；扫描件没有文字层、或 OCR 语言包不可用时，正文可能为空。

**Q：旧版 .doc/.ppt 没进索引？**
A：安装本机 LibreOffice 后重新扫描；索引页有安装入口和状态提示。

**Q：工作区删不掉？**
A：默认工作区不能删；非空工作区要先移走或删除其中的项目。

**Q：子项目的工作区选择框是灰的？**
A：子项目不能单独换区，会随父项目一起移动。

**Q：环境地址/外链能直接打开浏览器吗？**
A：当前版本提供地址复制；打开请粘贴到浏览器。

**Q：删除项目后还能恢复吗？**
A：界面不提供项目回收站；请用备份包恢复整库。删除前先导出备份。

**Q：数据存在哪里？**
A：界面底部显示实际数据库路径，通常在 `%APPDATA%\dev.zero.pfm\ledger.db`；同目录还有 WAL 文件和导入前的应急包。

## 16. 产品边界

本软件明确不做：

- 不管理 Git、不查看/提交代码
- 不管理数据库连接、不执行 SQL
- 不自动云端同步项目文件
- 不修改、移动、重命名本地原始项目文件

它只做一件事：把项目资料、路径、台账、待办、日报和检索索引集中登记在本机。
